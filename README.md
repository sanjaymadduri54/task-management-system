# Task Management System

A full-stack Task Management System built with **React** and **Spring Boot** that allows users to securely register, log in, and manage their tasks.

## Features

- User registration and login
- JWT-based authentication
- Secure password handling
- Create tasks
- View personal tasks
- Edit and update tasks
- Delete tasks
- Task status management
- Task priority management
- Dashboard analytics
- Responsive user interface
- CORS configuration for frontend-backend communication

## Dashboard Analytics

The dashboard provides simple task insights:

- Total Tasks
- TODO Tasks
- In Progress Tasks
- Completed Tasks
- High Priority Tasks
